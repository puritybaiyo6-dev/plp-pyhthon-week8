
# Personal Mini-Toolkit

## Project Description

My Personal Mini-Toolkit is a Python program that combines three useful tools in one menu-driven application.

## Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
2. **To-Do List Manager:** Allows users to add, view, and remove tasks.
3. **Number Guessing Game:** Challenges users to guess a random number between 1 and 10.

## Python Concepts Used

- Variables and data types
- Input and output
- Functions
- If, elif, and else statements
- While and for loops
- Lists and list methods
- F-strings
- Try and except error handling
- The random module

## How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run `python toolkit.py`.
4. Follow the numbered menu instructions.
